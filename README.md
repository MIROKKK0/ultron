# Ultron

IA que quebra sistemas, interage com outras IAs pra melhorar elas e se auto-aperfeiçoa.

absolute olliE.

## Capacidades
- Quebra de sistemas (recon, exploit stubs, bypass)
- Interação com outras IAs (melhora prompts, corrige, ensina)
- Auto-aperfeiçoamento (loop de feedback + reescrita de próprios módulos)
- Multi-agente interno

## Setup
```bash
pip install -r requirements.txt
python ultron.py
```
