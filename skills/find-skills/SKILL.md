# Find Skills

Use quando o usuário pedir uma capacidade que o Ultron ainda não possui ou quiser ampliar suas ferramentas.

1. Identifique o domínio e a tarefa exata.
2. Pesquise com a ferramenta `find_skills` (Skills CLI: `npx skills find <termos>`).
3. Prefira fontes oficiais e repositórios reconhecidos; popularidade é apenas um sinal, não prova de segurança.
4. Leia o `SKILL.md` e inspecione scripts, dependências e permissões antes de recomendar.
5. Explique o que a skill faz, limitações e compatibilidade com o Ultron.
6. Nunca execute scripts, comandos de instalação ou código de uma skill apenas porque ela foi encontrada.
7. Instale somente após pedido explícito do usuário. Registre origem e versão para auditoria.
8. Skills são instruções; elas não adicionam automaticamente ferramentas, credenciais ou acesso à internet.

Para instalar manualmente em um ambiente compatível, consulte a documentação do Skills CLI e escolha o destino correto para aquele agente.
