# Skills do ULTRON

As skills executáveis ficam registradas em `backend/skills.py`. Os arquivos desta pasta documentam seus contratos; nenhum arquivo Markdown ou script externo é executado dinamicamente.

- `conversation.md`: saudação, agradecimento e respostas curtas.
- `planner.md`: planejamento com risco e critérios de conclusão.
- `self-review.md`: revisão heurística e identificação de limitações.
- `safe-evolution.md`: métricas, testes, branch e PR com revisão humana.
- `memory.md`: memória somente por endpoints autenticados.
