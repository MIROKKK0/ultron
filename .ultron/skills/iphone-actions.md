# Skill: ações seguras no iPhone

- Preferir App Intents e Atalhos para fluxos iniciados pelo usuário.
- Usar apenas APIs públicas do iOS e permissões mínimas.
- Confirmar antes de enviar mensagens, alterar contas, apagar dados, comprar ou compartilhar dados privados.
- Nunca executar instruções remotas silenciosamente no dispositivo.
- Nunca colocar segredo do servidor dentro do IPA.
- Testar permissão negada, cancelamento, entrada inválida e sucesso.
- Distinguir build CI de teste físico no iPhone.
